native-macos

Same 120 logical queries and planned 3 ms arrival spacing in both cache modes. Fresh proxy/peers each trial; cache starts cold. Upstreams are real local UDP/TCP peers with a configured 6 ms async delay. Failover adds a silent first peer and 30 ms per-upstream deadline. Every result, including failures and generator lag, is retained. QPS is completed work over makespan at this fixed offered load, not maximum server capacity. TCP uses a fresh connection per query. RSS is sampled proxy-process RSS; clients, upstreams, kernel buffers and VM overhead excluded. Invocation latency excludes generator lag; scheduled p95 includes it.

Paired blocks: 3. No confidence interval or Internet/production claim.
